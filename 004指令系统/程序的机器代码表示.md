## 1. 常用汇编指令介绍

### 1.1 相关寄存器

X86有8个通用寄存器:

- EAX 累加器 Accumulator
- EBX 基地址寄存器 Base Register
- ECX 计数寄存器 Count Register
- EDX 数据寄存器 Data Register
- ESI 变址寄存器
- EDI 变址寄存器
- EBP 堆栈基指针 Base Pointer
- ESP 堆栈顶指针 stack Pointer

### 1.2 汇编指令格式

有两种不同的汇编指令格式, AT&T格式 和Intel 格式, 区别如下:

- AT&T格式中只能用小写字母, **Intel格式对大小写不敏感**

- AT&T格式中, 第一个数是源操作时, 第二个是目的操作数, **Intel格式中, 第一个是目的操作数, 第二个是源操作数, 方向从右到左.**

- AT&T格式中, 寄存器需要加前缀%,立即数需要加$, **Intel格式中，寄存器和立即数不需要加前缀**

- AT&T在内存寻址方面，需要加小括号\(), **Intel格式中, 内存寻址需要加中括号\[]**

  

汇编指令可以分为

- 数据传送指令
- 算术和逻辑运算指令
- 控制流指令



下面以Intel格式为例, 介绍一些常用的指令, 以下用于操作数的标记分别表示寄存器, 内存和常数.

- \<reg>: 表示任意寄存器, 若其后带有数字, 则指定其位数, \<reg32> 表示32位寄存器. \<reg16>表示16位寄存器.
- \<mem>: 表示内存地址, 如[eax], [var+4], 或者 dword ptr [eax + ebx].
- \<con>: 表示8位16位32位常数, \<con8>表示8位常数, \<con32>表示32位常数.

x86中的指令机器码长度是1Byte, 对同一指令的不同用途有很多种编码方式, 比如MOV指令有28种不同的机器码.

```assembly
mov ax, <con16>                // 机器码是B8H

mov al, <con8>                 // 机器码是B0H

mov <reg16>, <reg16>/<mem16>   // 机器码是89H

mov <reg8>/<mem8>, <reg8>      // 机器码是8AH

mov <reg16>/<mem16>, <reg16>   // 机器码是8BH
```





### 1.3 MOV指令

将第二个操作数的值复制到第一个操作数中.

```assembly
mov <reg>, <reg>
mov <reg>, <mem>
mov <mem>, <reg>
mov <reg>, <con>
mov <mem>, <con>
```

示例

```assembly
mov eax,ebx
mov byte ptr [var], 5
```

双操作数指令的两个操作数不能都是内存, mov指令不能用于直接从内存复制到内存.

如果需要在内存之间复制, 可以先复制到一个寄存器, 再从这个寄存器复制到内存.

### 1.4 PUSH指令

将操作数压入内存的栈, 常用于函数调用, ESP是栈顶, EBP是栈底. 入栈前先将ESP减4(栈增长的方向与内存地址的增长方向相反). 然后将操作数压入ESP所指向的地址.

```assembly
push <reg32>
push <mem>
push <con32>
```

### 1.5 POP指令

与PUSH指令相反, POP指令执行出栈操作, 出栈前先将ESP指示地址中的内容出栈, 然后将ESP值加4.

```assembly
pop eax     //弹出栈顶元素送到eax
pop [ebx]   //弹出栈顶元素送到ebx值指示的内存地址的4字节中.
```



### 1.6 ADD/SUB指令

- ADD指令将两个操作数相加, 结果保存到第一个操作数中
- SUB指令将两个操作数相减, 结果保存到第一个操作数中.



```assembly
add <reg>, <reg>   //  sub <reg>, <reg>
add <reg>, <mem>   //  sub <reg>, <mem>
add <mem>, <reg>   //  sub <mem>, <reg>
add <reg>, <con>   //  add <reg>, <con>
add <mem>, <con>   //  add <mem>, <con>
```



举例:

```assembly
sub eax, 10               // eax = eax -10
add byte ptr [var], 10    //将10与var值指示的内存地址的一字节值相加, 并将结果保存到var值指示的内存地址的字节中.
```

### 1.7 INC/DEC指令

这两个都是单操作数指令

- INC: 将操作数自加1
- DEC: 将操作数自减1

```assembly
inc <reg>
inc <mem>
dec <reg>
dec <mem>
```



举例:

```assembly
dec eax              // eax值自减1
inc dword ptr [var]  // var指示的内存地址4字节值自加1
```



### 1.8 IMUL 指令

有符号乘法指令, 有两种格式:

- 两个操作数, 将两个操作数相乘，结果保存在第一个操作数中, 第一个操作数必须是寄存器
- 三个操作数, 将第二个和第三个操作数相乘, 结果保存在第一个操作数中, 第一个操作数必须是寄存器

语法如下:

```assembly
imul <reg32>, <reg32>
imul <reg32>, <mem>
imul <reg32>, <reg32>, <con>
imul <reg32>, <mem>, <con>
```

乘法的结果可能会溢出, 则编译器将溢出标志位OF置为1.

### 1.9 IDIV指令

有符号整数除法指令, 它只有一个操作数, 即除数. 被除数是 `edx:eax`中的内容, 一共64位.

操作结果有两部分: 商和余数, 商送到eax,余数送到edx.

语法如下:

```assembly
idiv <reg32>
idiv <mem>
```

举例

```assembly
idiv ebx
idiv dword ptr [var]
```



### 1.10 AND/OR/XOR指令

逻辑与或异或指令, 两个操作数, 结果保存在第一个操作数里面.

这两个操作数不能同时为内存地址.

### 1.11 NOT指令

- 单操作数指令 
- 作用是位反转, 将操作数的每一位反转, 0变1, 1变0

### 1.12 NEG指令

- 单操作数指令
- 作用是取负.
- eax=5, neg eax --> eax = -5

### 1.13 SHL/SHR指令

- 双操作数指令
- 作用是逻辑移位, SH代表SHIFT, L表示LEFT左移, R表示RIGHT右移
- 结果保存在第一个操作数中.

### 1.14 JMP指令

无条件跳转指令.

### 1.15 JCONDITION 指令

有条件跳转指令, 根据标志位，决定是否跳转.



- JE
- JNE
- JBE
- JG
- JGE
- JLE





### 1.16 CMP/TEST指令

比较指令, 

- CMP , 比较两个操作数大小, 相当于进行 SUB指令, 但是只影响标志位, 不保存结果
- TEST， 将两个操作数进行按位与操作, 只影响标志位, 不保存结果.

CMP通常用来比较大小, 供 JE, JG等跳转指令来跳转.

TEST通常用来判断操作数是否为0. 

### 1.17 CALL/RET指令

Call和Ret指令分别用于实现函数的调用和返回.

语法如下：

```ass
call <label>
ret
```

call指令相当于进行

```assembly
push 0x0040 abcd  // 假设 0x0040 abcd 是call指令下一条指令的地址.
jmp  0x0040 1234  // 假设 0x0040 1234 是函数的入口地址.
```

ret指令相当于进行

```assembly
pop eax  //实际不是这样. pop出栈的地址是call指令压栈的地址.
jmp eax
```

## 4. 函数栈帧结构



```cpp
int add(int a, int b)
{
    return a+b;
}

int main()
{
    int a = 1;
    int b = 2;
    int c = add(a, b);
    return 0;
}
```





```tex
           高地址
              ↑

[EBP+12]  第二个参数 b
------------------------
[EBP+8 ]  第一个参数 a
------------------------
[EBP+4 ]  返回地址
------------------------
[EBP   ]  保存的旧 EBP
------------------------
[EBP-4 ]  局部变量1
------------------------
[EBP-8 ]  局部变量2
------------------------
[EBP-12]  局部变量3
------------------------
              ↓
           低地址
```
